Attach the owner's Post Lamp sprite (`post_lamp_style_reference.png`, the lit Post Lamp at 16x) to every prompt.
Source of every description: `docs/ART_DIRECTION.md`.

## Tips
- Start a new chat per prompt, and always attach the reference image.
- If colours drift, reply: "Use only the 14 listed hex colours, and make the pixels bigger and harder."
- If it comes out too detailed, reply: "Lower resolution: each character about 16 to 24 pixels tall on a 16 px grid, then scale up 8x with nearest neighbour."
